# CodeAlpha Ecommerce Sales Analysis# CodeAlpha Ecommerce Sales Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA), Data Visualization, and Sentiment Analysis using Python.

The project analyzes an e-commerce sales dataset and customer reviews to identify useful patterns, trends, and customer opinions.

## Tasks Completed

### Task 2: Exploratory Data Analysis (EDA)

- Explored the structure of the dataset.
- Checked rows, columns, and data types.
- Checked missing values and duplicate records.
- Analyzed sales and profit.
- Compared sales and profit across product categories.
- Identified top-selling products.

### Task 3: Data Visualization

Created visualizations to understand:

- Total Sales by Category
- Total Profit by Category
- Total Sales by Region
- Distribution of Sales
- Sales vs Profit
- Top 10 Products by Sales

### Task 4: Sentiment Analysis

Performed sentiment analysis on customer reviews.

- Analyzed customer review text.
- Classified reviews as Positive, Negative, or Neutral.
- Used TextBlob for sentiment analysis.
- Calculated sentiment counts and percentages.
- Created visualizations of sentiment distribution.
- Compared average ratings across sentiment categories.

## Objectives

- Analyze sales and profit performance.
- Identify patterns across categories and regions.
- Identify top-selling products.
- Understand the relationship between sales and profit.
- Analyze customer opinions from reviews.
- Present insights using clear visualizations.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- TextBlob
- Google Colab
- Jupyter Notebook

## Dataset

The project uses public datasets containing e-commerce sales data and customer reviews.

## Key Findings

1. Sales and profit performance were analyzed using Exploratory Data Analysis.
2. Product categories and regions were compared using visualizations.
3. Top-performing products were identified based on sales.
4. The relationship between sales and profit was examined.
5. Customer reviews were classified into Positive, Negative, and Neutral sentiments.
6. Sentiment percentages were calculated to understand overall customer opinions.
7. Average ratings were compared across sentiment categories.

## Conclusion

This project demonstrates the practical use of Python for data analysis, visualization, and sentiment analysis. EDA helped identify important patterns in sales data, while visualizations made the results easier to understand. Sentiment analysis provided insights into customer opinions and satisfaction based on review text.# CodeAlpha Ecommerce Sales Analysis
